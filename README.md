# Klakix Desktop

The Klakix video editor as a Windows app. It opens the same editor as [klakix.com](https://klakix.com) / [aivideoyap.com](https://aivideoyap.com) in its own window and adds desktop features:

- Save exported videos straight to any folder, then "Show in folder"
- Keeps the computer awake while an export is running
- Automatic updates: new versions download in the background and install on restart

**Download:** [Klakix-Setup-x64.exe](https://github.com/klakix-ai/klakix-desktop/releases/latest/download/Klakix-Setup-x64.exe) (Windows 10/11, 64-bit) · [all releases](https://github.com/klakix-ai/klakix-desktop/releases)

Your account, projects and credits are the same as on the website. On macOS and Linux, use the editor in your browser.

This repository hosts release builds only.
